The Core Idea

How can an AI "think more" without saying more?

Modern AI reasoning is dominated by Chain-of-Thought (CoT): models "think" by generating more text tokens. But a growing body of research shows that reasoning can happen in latent space — by repeatedly updating a hidden state vector without emitting intermediate natural-language tokens. This architectural shift changes fundamental trade-offs around compute efficiency, memory usage, latency, and observability.

Technical Mechanism

Token-Based Reasoning (Status Quo)

  • Intermediate representation: Text tokens appended to context
  • Additional compute: Generate more tokens (linear context growth)
  • Memory: KV cache grows O(context × hidden_dim)
  • Observability: High — human-readable reasoning trace

Latent Recurrent Reasoning (Emerging Paradigm)

  • Intermediate representation: Hidden state vector h ∈ ℝⁿ
  • Additional compute: Recurrent update hₜ₊₁ = f(hₜ, x)
  • Memory: Fixed-size state O(n²) independent of reasoning depth
  • Observability: Low — requires probes/visualization tools

BDH & BDH-CQ Connection

BDH (Dragon Hatchling) re-derives attention from biologically-inspired principles: neurons with sparse ReLU activations, synapses with Hebbian updates, local message passing. Attention emerges from synaptic state ρ = Σ VₜKₜᵀUᵗ⁻ᵀ. Fixed-size synaptic state replaces growing KV cache.

BDH-CQ adds in-context learning: demonstrations sequentially update recurrent synaptic memory (ρ ← ρ + η·h·xᵀ), then queries are solved through iterative latent reasoning without verbalizing intermediate steps. 29.5% ARC-AGI-1 pass@2 at $0.0007/task — 57× cheaper than GPT-5.6.

Why It Matters

  • Compute efficiency: Decouples reasoning depth from context length
  • Memory architecture: Fixed-size state vs. growing KV cache
  • Adaptive compute: Easy problems exit early; hard problems iterate longer
  • Cost frontier: BDH-CQ achieves 57× cost reduction vs GPT-5.6 at comparable accuracy

Limitations (Honest Assessment)

  • Observability gap: Hidden states require probes; no free lunch on interpretability
  • Diminishing returns: Accuracy plateaus; excessive recurrence causes saturation/oscillation
  • Memory fragility: Recurrent state overwritten by interference/forgetting
  • Composition gaps: BDH-CQ struggles with composition, ordering, nesting (16-31% on ConceptARC)
  • Training instability: Coconut needs careful curriculum; recurrent depth needs careful init

Evidence Discipline

Every claim in this submission is labeled: LIVE TOY (browser computation), PUBLISHED (from cited paper), TOY (pedagogical), ILLUSTRATIVE (conceptual diagram). No toy result is presented as a published result.

The Latent Reasoning Lab Artifact

An interactive browser-based laboratory where learners:

  1. Toggle between token vs latent reasoning on the same task
  2. Slide recurrent depth (1→32) and watch accuracy/compute trade-offs
  3. Watch hidden state heatmaps evolve in real-time
  4. Add demonstrations → watch recurrent memory update → query solved via latent loop
  5. Break the reasoner: add noise, interference, reduce state dim, increase depth
  6. Take a 7-question quiz + free-response with transparent rubric
